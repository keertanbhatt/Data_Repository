# Gujarat BOCW — Orders & Mail Repository (UI Demo)

Frontend-only prototype for the Gujarat Building & Other Construction Workers' Welfare Board. Uses mock data and static demo login credentials—no backend.

**Run locally:** `npm install` then `npm run dev`

**Demo logins:** Admin `admin` / `Admin@123` · GLO `glo` / `Glo@123` · PM `pm` / `Pm@123`
